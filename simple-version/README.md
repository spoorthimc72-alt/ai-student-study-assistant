# Simple version

This folder contains the easy-to-understand version of AI Student Study Assistant:

- `index.html` — page content and buttons
- `style.css` — colours, layout and responsive design
- `script.js` — AI tutor demo, notes demo, quiz, and planner interactions
- `StudyAssistant.java` — optional small Java example for a college viva; it is not required to run the website

Important: websites use **JavaScript**, not Java, for browser button interactions. Java is a separate backend/desktop language. The optional Java file is included only if your faculty asks you to show Java code.

To run it, open `index.html` in a browser.
